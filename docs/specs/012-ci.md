# 012 — Integración continua en GitHub Actions

Estado: aprobada
Depende de: [000, 001, 002, 005]
Bloqueada por dueño: no (opcional: activar protección de `main` con el check obligatorio, en GitHub)

## Por qué

Las puertas de calidad existen (`typecheck`, `lint`, `format:check`, `test:run`, `build`)
pero solo corren en la máquina del desarrollador, que además está afectada por el bloqueo
de iCloud. Un workflow en GitHub corre en disco local limpio y protege `main` y los previews
de Vercel.

## Alcance

Respeta 000. No añade dependencias npm.

Entra:

- `.github/workflows/ci.yml`: en `push` a `main` y en `pull_request`; `ubuntu-latest`; Node 22 con caché npm; `npm ci`; luego, en pasos separados y en este orden: `npm run typecheck`, `npm run lint`, `npm run format:check`, `npm run test:run`, `npm run build`. `CONTENT_SOURCE=local` como env del job.
- Badge de estado en README (una línea, sección Deploy).
- Recomendación (no acción automática): proteger `main` requiriendo el check `ci`.

No entra:

- Deploy desde Actions (lo hace Vercel, 009).
- Lighthouse en CI (008 se mide localmente; puede proponerse después).
- Matrices de Node, cachés de `.next`.

## Criterios de aceptación

1. DADO un push a `main`, CUANDO se ejecuta `gh run list --limit 1`, ENTONCES el workflow `ci` aparece con `completed success`.
2. DADO el log de la corrida, CUANDO se leen los pasos, ENTONCES los cinco comandos aparecen en el orden indicado y cada uno con exit 0.
3. DADO un PR con un error de tipo introducido a propósito en una rama de prueba, CUANDO CI corre, ENTONCES falla en `typecheck` (prueba de que la puerta enforce algo). La rama se borra después.
4. DADO `eslint --debug` en CI, ENTONCES el log muestra ≥ 28 archivos linteados (mismo criterio que 002).
5. DADO `README.md`, ENTONCES contiene el badge apuntando a `actions/workflows/ci.yml`.
6. DADO `.github/workflows/ci.yml`, CUANDO se ejecuta `npx prettier --check .github`, ENTONCES pasa.

## Verificación

```bash
gh run list --workflow=ci.yml --limit 3
gh run view --log | grep -E "npm run (typecheck|lint|format:check|test:run|build)"
# prueba negativa:

git checkout main && git branch -D ci-smoke && git push origin --delete ci-smoke
grep -n "actions/workflows/ci.yml" README.md
```
